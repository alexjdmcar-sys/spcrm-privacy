Политика конфиденциальности приложения SPCRM

Редакция от 26.10.2026

Приложение SPCRM («Приложение») — рабочая система для сотрудников Subarupolice: управление сделками, клиентами, каталогом запчастей, чат и задания команды. Приложением пользуются только сотрудники и партнёры, которым владелец сервиса выдал учётную запись. Регистрации для посторонних лиц нет.

1. Кто обрабатывает данные

Оператор данных — ИП Серышев М. (далее «владелец сервиса»).
Связь по вопросам данных: subarupolice@mail.ru

2. Какие данные обрабатываются

  • Данные учётной записи: имя, логин, роль и права доступа, пароль (хранится только в зашифрованном виде).
  • Рабочие данные, которые вносят пользователи: сообщения в чате и обсуждениях, задания, сделки, сведения о клиентах (имя, телефон), прикреплённые файлы и фотографии (например, чеки и накладные).
  • Технический идентификатор устройства для уведомлений: токен, выданный Apple (APNs) или Google (Firebase Cloud Messaging), и тип устройства. Он нужен только для того, чтобы присылать уведомления о новых сообщениях, упоминаниях и заданиях.
  • Служебные журналы: действия пользователей в системе (кто и когда изменил сделку или данные) для безопасности и разбора спорных ситуаций.

Приложение не собирает данные о местоположении, контакты телефона, содержимое других приложений и не использует рекламные идентификаторы.

3. Для чего используются данные

  • чтобы пользователь мог войти в систему и работать в рамках своих прав;
  • чтобы вести сделки, клиентскую базу, чат и задания;
  • чтобы отправлять уведомления на устройство и показывать число непрочитанного;
  • чтобы обеспечивать безопасность и учёт действий в системе.

4. Передача данных третьим лицам

Данные не продаются и не используются для рекламы или отслеживания. Данные передаются только тем, без кого невозможна работа сервиса:

  • Apple и Google — токен устройства и текст уведомления, чтобы доставить уведомление на телефон;
  • каналы связи с клиентами, подключённые владельцем сервиса (например, мессенджеры и социальные сети), — в объёме, необходимом для переписки с клиентами;
  • государственным органам — только по законному требованию.

5. Хранение и защита

Данные хранятся на серверах владельца сервиса. Доступ к ним защищён паролем, обмен данными с приложением идёт по защищённому соединению (HTTPS). Права пользователей ограничены ролью: каждый видит только то, что ему разрешено.

Данные хранятся, пока действует учётная запись и пока они нужны для ведения деятельности и выполнения требований закона.

6. Права пользователя и удаление данных

Вы можете запросить сведения о своих данных, их исправление или удаление учётной записи, написав на subarupolice@mail.ru. Мы ответим в разумный срок. Данные, которые закон обязывает хранить, будут удалены после окончания срока хранения.

Чтобы отключить уведомления, запретите их в настройках телефона (Настройки → Уведомления → SPCRM).

7. Дети

Приложение не предназначено для детей и не предлагается им.

8. Изменения политики

При изменении политики на этой странице появится новая редакция с новой датой.
